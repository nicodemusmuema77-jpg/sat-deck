How to use the SAT Strategy Deck

Start with one section and search for the skill you are practicing, such as transitions, linear equations, or test-day pacing. Read the rule and its explanation, open the timestamped source when you need more context, then apply the strategy to official practice questions. Mark a card practiced only after you have used it on a problem.

What this deck includes

The deck summarizes advice from five SAT preparation channels. It is a study reference, not official College Board guidance. For test format and timing, use the Digital SAT pacing guide, which links to current College Board sources. For official full-length practice, use Bluebook.
